# Notes CRUD App

A full-stack Notes Management Application that allows users to create, view, update, and delete notes through a simple and user-friendly interface.

## Live Demo
[Open Live Application](PASTE_YOUR_VERCEL_URL_HERE)

## Features
- Create new notes
- View all saved notes
- Edit existing notes
- Delete notes
- Store and retrieve notes using a REST API

## Tech Stack

**Frontend**
- React.js
- JavaScript
- HTML
- CSS
- Vite

**Backend**
- Python
- FastAPI
- REST API
- SQLite

## Run Locally

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
